# AI to Agent｜VAE 視覺化代理工程

用八張知識圖卡，從「請了數位員工，為什麼最後還是我做？」出發，練習交接、分工、執行與驗收。

![數位員工問題清單](<assets/cards/01-數位員工問題清單.png>)

## 從一項重複工作開始

資料用舊稿、溝通看不懂、報告還是錯。適合企業主、行政與行銷團隊挑一項交付物明確的工作試做，例如每週營運報告。先確認資料來源與授權人，再用已確認且可供練習的資料執行。

1. 依序閱讀下方八張圖卡。
2. 用 [VAE 方法指南](docs/method.md) 畫出交接流程、寫下分工及操作邊界。
3. 照 [週報實作範例](examples/weekly-report.md) 交付草稿和來源對照表，再依條件驗收。

這是方法論與教材專案，直接閱讀 Markdown 和 PNG 即可。週報範例使用虛構資料。
