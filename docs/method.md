# VAE 視覺化代理工程

VAE（Visual Agent Engineering）把人與 Agent 的分工、交接和驗收畫清楚，讓下一位接手者知道可以做什麼、遇到例外要找誰。

| 做法 | 本次任務的產物 |
|---|---|
| 第一性原理 | 回答用哪一版、交哪些檔案、怎樣算交對 |
| 費曼學習法 | 請第一次接手的人用自己的話說一遍，補上說不清楚的條件 |
| VAD | 畫出資料流、接手者與例外回報路線 |
| CDE（Card-Driven Engineering） | 保存團隊分工知識圖卡與工作流程任務圖卡 |
| VAC（Visual Agent Card） | 把啟動條件、輸入、操作邊界、輸出與驗收固化為可重用的任務圖卡 |
| 驗收 | 核對交付物，記錄總時間、退回次數及人工補做 |

## 兩張圖卡

**團隊分工知識圖卡**要回答成員有誰、誰指定邊界、誰製作、多久完成、誰檢查。

**工作流程任務圖卡**要回答何時啟動、調用哪個技能、交付什麼、缺件交回給誰。來源版本矛盾時，由來源負責人確認。對外發布由授權人決定。
