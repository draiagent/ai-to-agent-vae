# 請了數位員工，為什麼最後還是我做？

資料用舊稿，溝通看不懂，報告還是錯。交代 AI 做週報，開會前卻要自己重做，你遇過嗎？

如果換成剛到職的同事，你現在的交代夠他獨立做完嗎？這八張圖卡從這個問題出發。

1. **找痛點。** 先找出最耗時間的一步，例如每週追問哪份才是定稿。
2. **回到第一性原理。** 用哪一版、交哪些檔案、怎樣算交對？
3. **用費曼學習法練交代。** 請新手用自己的話說一遍。對方追問「差多少才算異常」，就把門檻寫清楚。
4. **用 VAE 定分工。** 人決定定稿、授權與發布，Agent 彙整、比較、附來源並產出草稿。
5. **用 VAD 畫交接。** 誰上傳、誰確認、誰接手？缺件就交原部門補，數字矛盾就交來源負責人確認。
6. **用 CDE 做圖卡。** 一張寫成員和分工，一張寫任務啟動、技能、交付和例外處理。
7. **用 VAC 跑一次實作。** 用真實工作情境立下交付條件，保留資料來源，跑完就核對成品。
8. **回到痛點驗收。** 草稿五分鐘完成，人工核對四十分鐘，四十分鐘也要算。一起比較總時間、退回次數與人工補做。

下次你說「算了，我自己來」時，記下你接手後做的第一個動作。那個你下意識會做、卻從來沒交代過的動作，就是第一張任務圖卡可以補上的內容。
